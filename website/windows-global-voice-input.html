WINDOWS VOICE INPUT GUIDE

Windows 全局语音输入：
按住说话，松手成字

打字并不是表达的唯一方式。Yurun 语润让语音直接进入当前光标所在的输入框：不切换窗口，不复制粘贴，也不替代你正在使用的输入法。

什么是“全局语音输入”？

它不是只在某一个软件里工作的麦克风按钮。全局语音输入意味着：无论你正在微信回复消息、在浏览器搜索、在 Word 写文档，还是在编辑器里写代码，只要那里能输入文字，就可以把光标放好后直接说话。

一条最短的路径：把光标放好 → 按住热键 → 说话 → 松开 → 文字进入当前输入框。

它和 Windows 听写、输入法语音有什么不同？

不同工具各有适合的场景。Yurun 的重点是让语音输入尽量贴近原本的键盘习惯：在需要输入时按住，输入完成时松开，随后继续正在做的事。它不要求你打开单独的录音界面，也不会替换微软拼音、搜狗或其他输入法。

适合哪些时候使用？

  • 长句和想法：一段自然语言通常说出来比敲出来更快。
  • 即时沟通：在聊天窗口中快速组织完整回复。
  • 搜索与写作：把搜索词、提纲、笔记和草稿直接说进输入框。
  • AI 工具：向 ChatGPT、Codex、Cursor 描述需求、问题和上下文。

如何开始？

  1. 从 GitHub Releases 下载并安装 Windows 版 Yurun。
  2. 启动后，在系统托盘打开设置，完成语音识别服务所需的配置。
  3. 把光标放进任意文本框，按住默认热键 ` 说话，松开后查看结果。

快速直接输入会尽量保留你原本的说话方式；当你确实需要润色或重新组织内容时，再按需使用 AI 智能整理。
