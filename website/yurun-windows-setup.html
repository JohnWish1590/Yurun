GET STARTED WITH YURUN

Yurun 安装与首次配置

用几分钟完成下载、启动和初始设置。完成后，只要把光标放在需要输入的位置，就能按住热键直接说话。

开始前需要什么？

  • 一台运行 Windows 10 或 Windows 11 的电脑。
  • 用于语音识别服务的 SAUC Key。
  • 如需使用“智能整理”，还需要配置所选 AI 服务的 API Key；快速直接输入不以 AI 润色为前提。

1. 从 Releases 下载 Windows 版

Yurun 的发布包托管在 GitHub Releases。进入发布页，下载最新 Windows 安装包或可执行文件；版本说明会写明本次改动。

打开 GitHub Releases

2. 启动后，在系统托盘找到语润

首次启动成功后，语润会以系统托盘图标的形式常驻。右键图标并打开“设置”，填写语音识别所需的 Key。请妥善保管自己的 API Key，不要把它发到聊天记录、截图或公开页面中。

默认使用习惯：光标放进输入框 → 按住 ` → 说话 → 松开。先在任意聊天框尝试一句短话，确认结果能进入当前输入位置。

3. 选择适合自己的输入方式

快速直接输入适合聊天、搜索、Prompt 和日常表达：它以尽量保留原话为原则，只进行少量低风险清洗。AI 智能整理适合把口述内容组织成更清晰的表述：需要时再启用即可。

4. 把高频词加入个人词库

人名、公司名、项目代号、英文缩写和专业术语最容易出现识别偏差。发现错误后及时纠正并记录，让 Yurun 更熟悉你常用的表达。

遇到问题怎么办？

可以在 GitHub Issues 提交问题。提供版本号、复现步骤和不含隐私信息的截图，会更容易定位问题。
