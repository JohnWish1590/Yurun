# 语润 Yurun · 全局语音润色输入悬浮工具

一个 **Windows 全局** 的语音转写 + AI 润色输入工具：按住热键说话，松手后自动转写、用大模型润色，再把润色后的文本**直接填进当前光标所在的输入框**（WorkBuddy、微信、浏览器、编辑器等任意软件）。

> **致敬声明 (Tribute)**
> 本项目高度致敬并源自 **心动网络 (makecindy)** 的开源 AI 语音润色算法框架 [Cindy](https://github.com/makecindy)，以及 **dash (dashhuang)** 极简、高效、即插即用的语音交互设计思想 [dash](https://github.com/dashhuang)。
> 项目的润色提示词复刻自 Cindy v17，语音识别默认走与 Cindy 同款的火山 SAUC 流式协议。感谢这些优秀作品提供的深厚技术积淀与交互灵感。

> **当前版本**：v1.2.1 — 双模式润色（轻润色「脱口成章」/ 轻清洗毫秒秒出）、托盘一键切换开关、实时浮窗 + 逐字吸走动画、打包崩溃修复。

## 一、它解决什么问题

大多数 AI Agent（例如各类桌面客户端的“麦克风”功能）属于**接收端 LLM**，在“点击麦克风 → 录音 → 发送”的链条里没有“发送前”的钩子。你只能在发送后才看到结果，无法在输入框里直接编辑润色后的文字。

**语润** 是一个独立的**外部前置全局工具**：

- 用全局热键触发录音（默认反引号 `` ` ``，Tab 键上方；支持 **按住说话** / **单击切换**）
- 录音结束自动高精度转写
- 把原始转写发给大模型做语义去噪、口语润色、中英混杂校正
- 最终**写回剪贴板并模拟 Ctrl+V**，直接填充并替换当前输入框里的光标位置

## 二、核心特性

### 🎯 双模式润色，想快想顺自己选（v1.2.1 核心）

系统托盘右键一键切换「润色」开关，两种模式都好用：

- **轻润色（默认开启）**：说话即出工整文字，**脱口成章**——口语里的口水字、重复、断裂被实时理顺，但语气和原意都留住。识别文字在浮窗里**边说边实时显示**，松手后润色结果逐字吸进输入框，丝滑不打断。
- **轻清洗（关闭润色）**：纯本地规则、毫秒级「秒出」。只剥短句/纯数字的句末标点，并清理少量低风险口语词（呃/嗯/哦/额/唉）；**刻意保留**「这个/那个/然后/其实/就是/的话」等本义词，以及「啊/呀/哎/吧」等语气词，绝不误伤语义。适合「我就想快点把话说出来、别给我加戏」的场景。

> 两种模式都满足「说话 → 光标处直接出现干净文字」，区别在于：轻润色做轻度语义理顺（走大模型），轻清洗只做规则级去噪（不走模型、零等待）。

### ✨ 边说边出的浮窗动画

- **录音中实时浮窗**：说话时，光标处浮现轻量浮窗，把识别中的文字**实时显示**出来（钉左缘、只往右/往下生长，不左右晃）。
- **逐字吸走动画**：松手后，浮窗里的字以约 30ms/字 的稳定节奏被「吸进」当前输入框，逐字可见、绝不一闪消失——打字的过程本身就成了反馈，体验非常舒服。
- **智能跟背景**：采样光标上方像素亮度，亮底界面用浅色浮窗，暗底用深色，任何软件里都不突兀。

### 🎙️ 悬浮药丸 + 即时热键

- **悬浮药丸 (Pill)**：录音/润色时，在 I 形光标（或鼠标）正下方浮现一个极简胶囊气泡，显示「● 正在录音」/「⟳ 正在润色」，不弹大窗、不打断工作流。
- **热键即时反馈**：按下瞬间即出「正在录音」，不吞事件、不抖动；前一句润色途中也能立刻录下一句（重叠录音）。
- **全局热键**：默认反引号 `` ` ``（Tab 键上方），支持 **按住说话** / **单击切换** 两种触发方式。

### 🌐 语音识别（云端火山 SAUC）

- **云端火山 SAUC（默认，Cindy 同款）**：WebSocket 二进制流式，自带 Gzip 实时压缩 + 大端 4 字节头封装，中英混杂与多方言识别强，且流式中间结果可被浮窗实时消费。识别 Key 在设置里填写，必填。

### 🤖 大模型润色（轻润色模式）

OpenAI 兼容接口，默认走**火山方舟（ARK）**（设置里 `api_base` 已预填方舟地址，填 `ark-` 开头的 Key 和 `ep-xxxx` 模型即可）；也支持 DeepSeek / 阿里百炼等任意 OpenAI 兼容端点，改 `api_base` / `api_model` 即可，代码无需改动。复刻 Cindy v17 提示词，带**发散护栏**（输出过长/偏离原文则回退原文）。

### 🖥️ 其它贴心设计

- **苹果风设置界面**：圆角 Segmented 选项卡 + 白色圆角卡片，一屏展示，无滚动条。
- **系统托盘常驻**：开机自启可配，退出/设置都从托盘走。
- **单实例锁**：启动时自动清理同名 / 同目录的旧进程（含无托盘图标的僵尸进程），永远只跑一个 Yurun，避免旧进程占用全局热键导致注册失败。
- **润色不再误吞前文**：长句润色完成后，只把最终文本一次性粘贴到光标处，不再触发撤销 / 选区替换，彻底解决「润色后把前面已输入内容覆盖掉」的问题。
- **短句直出**：转写结果较短时跳过润色，直接填入，省去等待。
- **热键冲突提示**：若全局热键已被其它程序占用，悬浮 pill 直接提示「热键被占」并在日志记录具体错误码，不再弹大窗。

## 三、架构

纯 Python 3.12，采用 **主线程 UI 渲染 + 子线程后台逻辑（Queue 消息泵）** 的经典高内聚、低耦合架构，100% 线程安全。

```
                      [ 全局键盘钩子 (hotkey.py) ]
                                    │  触发开始 / 结束录音
                                    ▼
   [ 托盘常驻 (tray.py) ] ─► [ 应用主循环 (main.py) ] ─► [ 浮空胶囊 (pill.py) ]
                                    │
                  ┌─────────────────┴─────────────────┐
                  ▼                                   ▼
     [ 云端火山 ASR (sauc_asr.py) ]           [ 麦克风采集 (recorder.py) ]
                  └─────────────────┬─────────────────┘
                                    ▼
                       [ 语义润色 (refiner.py) + prompts/ ]
                       - Cindy v17 Prompt，OpenAI 兼容端点
                       - 发散护栏、JSON 容错解析
                                    ▼
                       [ 光标焦点写入 (main.py) ]
                       - 写入系统剪贴板 + 模拟 Ctrl+V / PowerShell SendKeys 兜底
```

| 模块 | 职责 |
|------|------|
| `main.py` | 主循环、UI 消息泵、录音→识别→润色→粘贴全流程编排 |
| `hotkey.py` | 低级键盘钩子，按住说话 / 单击切换，即时触发与去抖 |
| `pill.py` | 无边框半透明悬浮胶囊，跟随 I 形光标 / 鼠标，智能跟背景 |
| `tray.py` | 系统托盘图标与菜单 |
| `gui.py` | macOS/iOS 风格的配置窗口（Segmented、卡片） |
| `sauc_asr.py` | 火山 SAUC WebSocket 二进制流式协议（Gzip + 大端 4B 头） |
| `recorder.py` | 麦克风采集（sounddevice） |
| `refiner.py` | 大模型润色（Cindy v17 提示词 + 发散护栏） |
| `config.py` | 配置读写（`%APPDATA%\Yurun\config.json`） |
| `logger.py` | 日志（`%APPDATA%\Yurun\logs\yurun.log`） |
| `prompts/` | `refine-dictation.zh.txt` / `.en.txt`（Cindy v17 润色提示词） |

## 四、安装与运行

### 方式 A：下载 EXE（推荐，普通用户）

1. 到 [GitHub Releases](https://github.com/JohnWish1590/Yurun/releases) 下载最新版 `Yurun-vX.Y.Z.exe`（单文件，约 70MB）。
2. **双击即可运行**，无需安装 Python、无需装任何依赖。
3. 首次运行会在 `%APPDATA%\Yurun\` 生成 `config.json`，系统托盘出现语润图标，填好两个 Key（见下一节）就能用。

> 想开机自启：把 `语润.exe` 快捷方式放进「开始菜单 → 启动」文件夹即可。

### 方式 B：源码运行（开发者）

需要本地有 Python 3.10+（建议 3.12）和环境：

```powershell
pip install -r requirements.txt
python src/main.py        # 直接运行
# 或双击 run_yurun.bat（自动定位 python）
```

### 自行打包为独立 EXE（可选）

源码运行即可，若想自己从源码构建分发：

```powershell
pyinstaller Yurun.spec --noconfirm     # 产物：dist/语润.exe
# 再跑 Inno Setup 生成安装包（脚本会读取 dist/语润.exe）：
& "C:\Users\<你>\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer/yurun_setup.iss
# 产物：dist/语润-Setup-1.2.1.exe
```

## 五、配置

右键托盘图标 → **设置**，分两张卡片：

### 识别卡片（必填）

| 配置项 | 说明 | 获取 |
|--------|------|------|
| **火山 SAUC Key**（语音识别） | 火山引擎「语音技术」产品的 App Key，**必填**，不填无法识别 | [火山语音技术控制台](https://console.volcengine.com/speech) |

### 润色卡片（可选）

| 配置项 | 说明 | 获取 |
|--------|------|------|
| **润色 API Key** | OpenAI 兼容端点的 Key（`sk-` / `ark-` 等均可） | 见下方说明 |
| **API Base** | 默认 `https://ark.cn-beijing.volces.com/api/v3`（火山方舟） | 任意 OpenAI 兼容 `/v1` 或 `/v3` |
| **模型名** | 如方舟的 `ep-xxxx` 接入点、或 `deepseek-chat` 等 | 对应平台控制台 |

> ⚠️ **识别 Key 和润色 Key 是两回事，分开填**：
> - **识别**用的是「火山语音技术」的 SAUC Key（独立字段，必填）。
> - **润色**用的是大模型 Key（可选）。默认推荐**火山方舟（ARK）**（`ark-` 开头，默认 `api_base` 已填好方舟地址）；也支持 DeepSeek / 阿里百炼等任意 OpenAI 兼容端点，改 `api_base` / `api_model` 即可，代码无需改动。
> - 若**不填润色 Key**，程序仅支持「轻清洗」模式，托盘右键的「润色」菜单项会自动置灰不可用；填写后重启即可启用。

## 六、使用

1. 把光标放到任意软件的输入框（如微信聊天框、浏览器搜索栏）。
2. **按住**反引号键 `` ` ``（Tab 上方那个键）说话，松手即开始转写 + 润色。
3. 稍候，润色后的文字自动填入当前输入框（浮窗会边识别边显示、松手后逐字吸进输入框）。
4. 也可在设置里改成「单击切换」模式。
5. **切换轻润色 / 轻清洗**：系统托盘右键 → 勾选/取消「润色」。
   - 想要口语被实时理顺、脱口成章 → 保持勾选（默认）。
   - 想要秒出、零等待、只去口水字 → 取消勾选，走本地轻清洗。

## 七、已知限制与说明

- **润色延迟取决于所选大模型端点（与语音识别无关）**。这里的延迟指「润色大模型」的生成耗时，不是识别速度——语音识别（ASR）本身首字约 1~1.5s，识别文字会在浮窗里实时显示。润色大模型当前默认火山方舟（ARK），首字通常在 1~2s 量级；若想更快可切换到其它低延迟端点。
- 仅支持 Windows（依赖 Win32 光标抓取与全局热键）。
- **流式识别「重复收敛」**：录音过程中浮窗（partial）可能把「有点意思」之类重复显示数次，这是火山 SAUC 流式中间结果抖动，松手后服务端收敛为一次最终结果。本地无法还原被 ASR 收敛掉的内容，属正常现象。
- **轻清洗（润色关闭）不做语义理解**：它只按规则剥标点/删少量语气词，不会像 LLM 那样重组句子；如需通顺改写，请保持润色开启。

## 八、日志与问题反馈

程序会把**完整运行日志**写到：

```
%APPDATA%\Yurun\logs\yurun.log
```

- 日志自动轮转（单文件 ≤ 1MB，保留最近 3 份）。
- **任何未捕获异常**（主线程 / 子线程 / 界面回调）都会**自动写入该文件**，并附上 `请将以上日志发给开发者反馈问题` 提示——你无需截图黑框。
- 启动时会写入版本 / Python / 平台信息（banner），便于定位环境。
- **遇到 bug 时**：右键托盘图标 → **「打开日志目录」**，把 `yurun.log` 发给我即可。

> 日志目录即 `%APPDATA%\(程序名)`，程序名固定为 `Yurun`，故路径恒为
> `C:\Users\<你>\AppData\Roaming\Yurun\logs\yurun.log`。
