MODEL SETUP GUIDE

Yurun 需要申请哪些模型？

Yurun 采用 BYOK（使用你自己的 Key）。需要准备的只有两类服务：必填的语音识别（ASR），以及可选的 AI 智能整理。前者负责把声音变成文字；后者仅在你选择“智能整理”时使用。

先说结论：只想做到“按住说话，松手出字”，申请第一项即可。第二项不是必需，没填也能正常快速输入。

1. 必填：豆包大模型流式语音识别 2.0

ASR · 语音转文字

这是 Yurun 默认使用的实时语音识别服务。它会在你按住热键说话时流式识别，并在松开后把最终文字写入当前输入框。

去哪里申请？

打开 豆包语音控制台，登录火山引擎账号。在左侧“开通管理”中开通大模型流式语音识别 2.0，并创建或选择自己的豆包语音应用。

申请后要拿什么？

复制该语音应用的 App Key / API Key。在 Yurun 的系统托盘中打开“设置”，在“语音引擎”卡片的 API Key 填入并点击右侧“确定”保存。

Yurun 已预填流式语音识别 2.0 所需的端点和资源 ID，通常不需要打开“高级”修改。当前默认资源 ID 是：

volc.seedasr.sauc.duration
（大模型流式语音识别 2.0 小时版）

协议中的模型类型固定为 bigmodel；这些是程序连接服务时的内部参数，不需要手动填写模型名称。

有免费额度吗？

火山引擎目前公开页面列有豆包流式语音识别的新用户试用额度。具体可用额度、有效期、价格和账户资格会随活动与地区变化，请以你登录后的控制台计费页显示为准，再决定是否开通付费。

前往豆包语音控制台

2. 可选：火山方舟 AI 智能整理

LLM · 润色与整理

智能整理会在识别完成后，按你的需要把口述内容润色、改写或组织成更清晰的文字。它不影响快速直接输入：不配置 Key 时，Yurun 仍然可以作为全局语音输入工具使用。

去哪里申请？

打开 火山方舟控制台。在“在线推理”中创建推理接入点，选择合适的 Doubao-Seed 系列模型；创建完成后，记录接入点 ID（常以 ep- 开头）和 API Key。

在 Yurun 里怎么填？

  1. 打开系统托盘中的“设置”，找到“智能整理 API（可选）”。
  2. 在 API Key 填入火山方舟 Key 并点击“确定”。
  3. 展开“高级”，把 Base URL 设置为 https://ark.cn-beijing.volces.com/api/v3。
  4. 把 模型 填为刚创建的方舟推理接入点 ID，例如 ep-202…。

如果不确定选择哪个模型，可以先在方舟控制台选择适合在线推理的 Doubao-Seed 系列。模型能力、可用区域、限额和价格均以控制台展示为准。

前往火山方舟控制台

安全提醒

API Key 只应填进本机的 Yurun 设置中。不要把 Key 发到聊天记录、Issues、截图、公开网页或代码仓库。遇到疑似泄露时，请立刻在相应控制台禁用或轮换 Key。
